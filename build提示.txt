## 本地预览

# 首次使用: 复制 .env.example 为 .env 并填入 Cloudflare 凭据（可选，仅语义搜索需要）
copy .env.example .env

.\start-local.bat                 # 启动 HTTP 前端 + 语义搜索（如有 .env）
# 打开 http://localhost:5500/commands.html

## 指令执行

# 指令执行通过 CF Pages Function 实现（functions/api/command.js），
# 部署到 Cloudflare Pages 后自动生效，手机和 PC 均可使用。
# 本地开发时如需测试指令执行，使用 wrangler dev 或直接推送部署。

## 重新生成 Embedding（更新 commands.json 后运行）

# PowerShell:
$env:CF_ACCOUNT_ID="你的账号ID"   # CF Dashboard 右下角
$env:CF_API_TOKEN="你的Token"     # My Profile → API Tokens → Workers AI 权限
node build.js                     # 生成 embeddings.json，提交后自动部署

node test-search.js "保存飞船"    # 本地测试脚本，可以测试嵌入模型效果

## 文件说明

commands.json            指令数据，日常维护的入口
embeddings.json          由 build.js 生成，勿手动编辑
build.js                 生成脚本，需要上方两个环境变量
functions/search.js         CF Pages Function，语义搜索接口
functions/api/[[route]].js  CF Pages Function，指令执行 + 健康检查（TCP → SE 服务器）
commands.html            前端页面，fetch commands.json 动态渲染
command-autocomplete.js  指令补全模块（Trie + 语义纠错）
command-executor.js      指令执行模块（登录管理 + 执行按钮 + 用量限制）
config.json              配置文件（模型名称、搜索端口、桥接端口）
.env.example             环境变量模板（复制为 .env 后填入凭据，.env 已 gitignore）
start-local.bat          本地开发一键启动脚本（自动加载 .env）
